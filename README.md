# BookMyStay Hotel Booking System

A full-stack hotel booking application built using Java Spring Boot, Angular 19, and PostgreSQL.

Project Status

Currently in development

Backend development completed
REST APIs implemented and tested
Database integration completed using PostgreSQL and Spring Data JPA
Angular frontend currently under development

## Features

- Hotel search and booking management
- RESTful API architecture
- Angular frontend
- PostgreSQL database integration
- Spring Data JPA/Hibernate
- Server-Side Rendering (SSR)

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate

### Frontend
- Angular 19
- TypeScript
- HTML/CSS

### Database
- PostgreSQL

### Tools
- Maven
- Git
- Docker

## Project Structure

BookMyStay(backend)/
BookMyStay(frontend)/

## Installation

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
ng serve
```
